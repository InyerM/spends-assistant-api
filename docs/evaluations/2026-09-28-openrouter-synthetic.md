# OpenRouter synthetic validation

Date: 2026-09-28 (America/Bogota). These checks used the local `OR_API_KEY` and synthetic financial text or a synthetic image with two receipts. They did not use production financial records, did not write to Supabase, and did not deploy the Worker. Costs below are the values returned by OpenRouter for these specific calls, not monthly estimates.

| Check                                                          | Result                                                                                                                                       |            Observed cost | Limitation                                                         |
| -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | -----------------------: | ------------------------------------------------------------------ |
| DeepSeek V4.1 Flash text, first 17 fixtures                    | 92.8% field accuracy, 94.1% JSON/schema validity; one invalid JSON response                                                                  |                 $0.00317 | Single pass is variable; not a production acceptance result.       |
| DeepSeek V4.1 Flash text, 17 fixtures repeated twice           | 100% field and schema validity across 34 calls; p50 2,180 ms, p95 13,738 ms                                                                  |                 $0.00475 | Synthetic fixtures only.                                           |
| Qwen3 VL 30B text, 17 fixtures                                 | 98.6% field accuracy, 100% JSON/schema validity; one relative-date mismatch; p50 1,731 ms, p95 3,145 ms                                      |                 $0.00880 | Synthetic fixtures only; routed without ZDR.                       |
| Qwen3 VL 30B image, one screenshot with two synthetic receipts | Both visible amounts (COP 12,000 and COP 5,000) were extracted as separate observations; 2,894 input and 328 output tokens; 22,481 ms        |               $0.0006309 | One synthetic image is insufficient to measure OCR accuracy.       |
| Qwen3 VL 30B with ZDR                                          | HTTP 404: no endpoint matched the zero-retention policy                                                                                      | No successful extraction | ZDR cannot currently be required for this model/account route.     |
| Qwen3 VL 235B image escalation                                 | Two adapter attempts returned HTTP 200 with no usable JSON; a simple later request returned HTTP 429 from an overloaded upstream shared pool |              Unavailable | Do not treat this escalation as validated or enable automatic use. |

The text evaluation code and fixture IDs are in `scripts/eval/text-models/`; the request-building tests are in `tests/eval/text-models/`, and the image adapter tests are in `tests/ai/vision.test.ts`. The synthetic receipt PNG was generated locally outside the repository and is not a durable accuracy fixture.

OpenRouter [distinguishes zero retention from data collection controls](https://openrouter.ai/docs/guides/get-started/sovereign-ai). After the 404, the user permitted Qwen without ZDR while requiring no training. The adapter therefore sends `provider.data_collection: "deny"`; this can permit transient provider retention. Text requests still require ZDR. Provider eligibility and behavior must be rechecked before production deployment.

Next validation: use a consented, redacted set of actual bank screenshots and ambiguous transaction text; score missed and false movements, amount/date/counterparty accuracy, JSON validity, latency, and cost per accepted observation. The 235B route needs a successful structured image response or a different escalation model before it is enabled.
