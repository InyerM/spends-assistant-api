Use the smallest capable GPT model and the least context that can complete the task reliably. For bounded searches, simple documentation, formatting, and mechanical refactors, use Codex Luna. For feature work, meaningful tests, and reviews requiring judgment, use Codex Sol. Reserve Codex Astra for genuinely complex architecture, security or tax reasoning, and hard debugging; escalate only after naming the concrete blocker. Delegate to GPT agents only.

Delegate only independent, well-scoped work. Give each agent the goal, owned files, constraints, acceptance criteria, and required checks; send a concise summary instead of the full conversation. Avoid recursive delegation. The primary agent reviews every change. Write a failing test before changing behavior, then run focused tests and all required project checks. For documentation or type-only refactors, verify the relevant links, formatting, types, and behavior. Report what ran, what remains uncertain, and any human validation needed. Never save tokens by skipping correctness or safety gates.
